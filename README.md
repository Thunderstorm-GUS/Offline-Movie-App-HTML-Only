# Local Movie Tracker

A local movie tracking web application designed to help organize watched films. Built as a standalone single-file bundle (`Movie app.html`) powered by React (`19.3.1`) and configured with web app and Open Graph metadata .

## Overview

- **Application Title:** `Local Movie Tracker` 
- **Description:** A local movie tracking application that helps you organize your watched films .
- **Delivery Format:** Standalone single-file HTML bundle (`Movie app.html`)

## Key Metadata & Web App Configuration

Configured inside `Movie app.html` :
- **Responsive Viewport:** Scales to device width at initial scale `1.0` (`width=device-width, initial-scale=1.0`) .
- **Theme Color:** `#0b161c` 

## How to Use (Tutorial)

### 1. Launch the App
- **Via Local Web Server (Recommended):** Place `Movie app.html` in a folder and serve it with a local static server (for example, VS Code Live Server or `npx serve .`), then open the local URL in your browser .
- **Direct Open:** Double-click `Movie app.html` to open it in a desktop or mobile browser . (If a browser blocks local `file://` module behavior, use a local static server instead .)

### 2. Open the browser App
- Open the hosted or locally served page in your browser .
- Tap your browser's **Share** menu and choose **Add to Home Screen** to launch it in standalone web app mode under the title `MovieTracker` with theme color `#0b161c` .
- Import your movie file from your file explorer (Note: The selected file is not going to appear it will be opened and all of the content inside will open.)

### 3. Organize Your Watched Films
- Use the on-screen interface once the bundle mounts to add, view, and organize the movies you have watched .
- Keep your browser storage and session intact on the device/origin you use to track your films, or host the file on your own static server or local network portal for quick access across devices .
